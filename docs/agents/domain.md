# Domain docs

This is a single-context repository.

Before exploring a feature, read the root [`CONTEXT.md`](../../CONTEXT.md) and
the relevant decisions in [`docs/adr/`](../adr/). Use the canonical vocabulary
from `CONTEXT.md` in issues, specs, tests, and code discussions. Keep
`CONTEXT.md` free of implementation details; record durable architectural
trade-offs in an ADR.
